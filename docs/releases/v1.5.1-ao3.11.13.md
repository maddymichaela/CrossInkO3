# CrossInk AO3.11.13

AO3.11.13 fixes the local install failure that could occur after AO3 had already found and downloaded a new chapter successfully on X3.

## Chapter Installation

The updater already validates the temporary download as a ZIP/EPUB, confirms its exact AO3 work ID, and requires an embedded update date before touching the original book. Installation now treats only these operations as safety-critical:

- Backing up the current EPUB.
- Moving the validated download into place.
- Clearing generated EPUB data while preserving CrossInk progress, reader settings, dictionary history, AO3 state, and reading statistics.

The second full EPUB load and AO3 metadata scrape is no longer allowed to reject an otherwise valid update. This removes the failure reported as **Could not safely install the AO3 update** after chapter discovery and download had both succeeded.

## Metadata Fallback

Before clearing generated cache data, the updater reads the existing AO3 library card. It restores that card with the new update date and completion state, then attempts the richer metadata refresh.

If the X3 cannot complete that optional refresh immediately, the new EPUB remains installed and the fic remains visible in the AO3 Library. Chapter count, word count, summary, or tags may retain their previous values until **Refresh Metadata** is run later.

## X3 Memory

Wi-Fi is turned off after the validated EPUB has been installed and before the optional EPUB cache/metadata pass. This releases network heap that is no longer needed and gives the X3 more room to rebuild the book cache.

Rollback no longer triggers another immediate cache rebuild and AO3 scrape. If a real SD operation fails, the updater restores the original EPUB directly and reports the failing stage instead of only showing a generic safe-install message.

## Confirmed From AO3.11.12 Testing

- AO3 update discovery reaches the new-chapter result.
- AO3 EPUB download and embedded work-metadata validation succeed.
- Grimmory OPDS browsing and book download succeed on X3.

## Firmware

For an X3 or standard X4, flash `CrossInk-AO3-v1.5.1-ao3.11.13-x3-x4.bin`. The boot screen should report `1.5.1-ao3.11.13`.

Do not flash the X3/X4 image on X4 Pro, X4 Classic, or Sticky hardware. No AO3 reindex, cache deletion, or settings reset is required.
