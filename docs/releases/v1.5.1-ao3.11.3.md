# CrossInk AO3.11.3

AO3.11.3 makes CrossInk's finished-book folder configurable for the whole reader and keeps archived books out of end-of-book recommendations.

## Selectable Read Folder

- Open **Settings > System > Read Folder** to choose an existing folder on the SD card.
- The setting applies to normal completed EPUBs and AO3 fics moved by **Move Finished Books to Read Folder**.
- Existing settings continue to use `/Read` until another folder is selected.
- Selecting the SD-card root safely falls back to `/Read`.

AO3 fics still preserve their original relative folder structure and can be restored to their recorded original location. Changing the Read folder does not invalidate existing restore records.

## Recommendation Behavior

Books inside the selected Read folder or any of its subfolders are not shown on the end-of-book screen. This applies to both ordinary next-book suggestions and AO3 same-series suggestions. The device displays this behavior in a confirmation notice before opening the Read-folder picker.

## Firmware

For an X3 or standard X4, flash `CrossInk-AO3-v1.5.1-ao3.11.3-x3-x4.bin`. The boot screen should report `1.5.1-ao3.11.3`.

Do not flash the X3/X4 image on X4 Pro, X4 Classic, or Sticky hardware. Those devices require their board-specific build.
