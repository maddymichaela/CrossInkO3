# CrossInk AO3.10.2

AO3.10.2 is a performance update over AO3.10.1 for readers using AO3 series continuation.

## Changes

- Finds later works in the same AO3 series through the compact library index instead of opening every cached EPUB metadata sidecar.
- Releases the previous rendered section before opening a selected series work.
- Shows loading feedback while CrossInk finalizes the old reader state and opens the next EPUB.

## Firmware

Flash `CrossInk-AO3-v1.5.0-ao3.10.2-x3-x4.bin` only on an X3 or standard X4. The boot screen should report `1.5.0-ao3.10.2`.

## Validation

- Production X3/X4 firmware built successfully for the tagged source.
- The existing AO3 parser and rating-filter host tests passed.
- This release remains based on CrossInk 1.5.0.

All AO3.10.1 features remain included, including AO3 browsing and indexing, five fic states, on-device chapter updates, longfic pinning, rating filters, ignored folders, auto-indexing, AO3-aware archiving, and restoration to original nested folders.
