# CrossInk AO3.11.10

AO3.11.10 handles the HTTP 403 response observed on X3 when checking a public AO3 work. A 403 from the HTML work page no longer automatically means that the work is locked.

## Direct EPUB Fallback

- If AO3 blocks the streamed work page with HTTP 403, CrossInkO3 requests the work's current EPUB directly.
- The EPUB is streamed to a temporary file on SD rather than retained in RAM.
- CrossInkO3 opens the temporary EPUB and reads its AO3 preface to recover the work ID, update date, and completed/WIP state.
- The update is offered only when the embedded work ID matches the current fic and its date is newer.
- Pressing Update installs the already validated temporary EPUB instead of downloading it a second time.

If AO3 also returns 403 for the EPUB itself, the work may be locked or AO3 may be blocking both endpoints. Locked works remain unsupported.

## Download Safety

The fallback retains temporary-file ZIP validation, exact work-ID matching, backup and rollback, cache-preserving installation, and reader-data preservation. Temporary validation does not write AO3 sidecars or add a temporary path to the library index.

Framebuffer-backed EPUB inspection is serialized with rendering to reduce X3 crash risk. No AO3 library, settings, cache, or reading-state schema changed.

## Firmware

For an X3 or standard X4, flash `CrossInk-AO3-v1.5.1-ao3.11.10-x3-x4.bin`. The boot screen should report `1.5.1-ao3.11.10`.

Do not flash the X3/X4 image on X4 Pro, X4 Classic, or Sticky hardware.

## Validation

- Full production ESP32-C3 X3/X4 firmware build completed successfully with 384,576 bytes free in the OTA application partition.
- Native AO3 EPUB identity extraction is compiled into the firmware and does not persist temporary index records.
- The direct endpoint for the reported public work returned a valid AO3 EPUB during desktop verification.
- Hardware validation is still required for the complete on-device check, prompt, and install sequence.

No AO3 reindex, cache deletion, settings reset, or archive migration is required.
