# CrossInk AO3.11.1

AO3.11.1 fixes the on-device firmware updater for the CrossInkO3 fork. It contains the complete AO3.11 feature set and remains based on CrossInk 1.5.1.

## Firmware Update Fix

- **Settings > Check for Firmware Updates** now reads the latest release from `maddymichaela/CrossInkO3`, not `uxjulia/CrossInk`.
- The updater accepts this fork's `CrossInk-AO3-...-<board>.bin` filenames as well as canonical CrossInk firmware names.
- Board filtering remains enforced, so an X3/X4 build cannot select an X4 Pro, X4 Classic, or Sticky image.
- AO3 release suffixes are compared numerically. For example, `ao3.11.1` is newer than `ao3.11`, and `ao3.12` is newer than `ao3.11.9`.

## One-Time Manual Upgrade

Firmware running `ao3.11` or older cannot discover this fix because its updater still contacts upstream CrossInk. Flash `CrossInk-AO3-v1.5.1-ao3.11.1-x3-x4.bin` manually once. Future update checks will then follow CrossInkO3 releases.

Do not flash the X3/X4 image on X4 Pro, X4 Classic, or Sticky hardware. Those devices require their board-specific build.

## Validation

- Production X3/X4 firmware build passed with 397,824 bytes free in the OTA partition.
- Six focused host tests passed for AO3 version ordering, release-candidate handling, fork asset recognition, and wrong-board rejection.
- The built image contains version `1.5.1-ao3.11.1` and the CrossInkO3 GitHub Releases API endpoint.

## Lineage

This fork uses [CrossInk](https://github.com/uxjulia/CrossInk) as its base and selectively adapts the AO3 concepts pioneered by [AvesO3](https://github.com/SiliconAves/AvesO3). AO3 EPUBs continue to open in the normal CrossInk reader.
