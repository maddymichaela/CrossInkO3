# CrossInk AO3.11

AO3.11 updates the fork to CrossInk 1.5.1 while retaining the complete AvesO3-inspired AO3 experience and keeping CrossInk's reader behavior authoritative.

## CrossInk 1.5.1 Base

- Adds upstream X4 Pro and X4 Classic support, board-aware firmware validation, custom boot screens, Quick Lock improvements, keyboard layouts, and expanded touch controls.
- Adopts the newer touch reader menu and FreeInk SDK.
- Includes upstream EPUB layout, clipping, dictionary, input, sleep, Wi-Fi, memory, and rendering fixes.
- Includes CrossInk 1.5.1 KOReader Sync reliability fixes, including preservation of reader orientation/settings and cleaner network transitions.
- Wi-Fi passwords remain visible while typing, including the updated landscape-aware keyboard flow.

## AO3 Integration Retained

- AO3-style library with metadata squares, summaries, Automatic and Folder Tree modes, sorting, fandom/relationship filters, multi-select content ratings, and Hide Finished Fics.
- Native AO3, Calibre/FanFicFare, and Kobo-converted EPUB recognition.
- Manual and automatic indexing in batches up to 50, with ignored-folder multi-select.
- Unread, Reading, Waiting for Chapter, New Chapter Available, and Finished states in the AO3 Library and File Browser.
- Manual status changes, automatic Waiting assignment for WIPs, Home pinning, return to the previous AO3 row, and same-series continuation.
- End-of-book and reader-menu AO3 update checks with validated download, backup, rollback, metadata rebuild, and CrossInk state preservation.
- AO3-aware move to `/Read`, original nested-folder preservation, and restore-to-original-folder behavior.

## Merge Fixes

- Preserves AO3 navigation and update actions in the v1.5.1 activity and reader-menu model.
- Integrates AO3 series suggestions with the v1.5.1 lazy end-of-book loader.
- Uses the current v1.5.1 icon set for AO3 status indicators.
- Removes obsolete result variants and duplicate metadata filtering introduced at the branch boundary.

## Cache Migration

The AO3 fork remains on book-cache version 10 because its serialized core metadata includes AO3 work ID, update date, and completion data. Existing AO3 version 10 caches do not need another rebuild. A device coming from stock CrossInk 1.5.1 uses cache version 9, so EPUB caches rebuild once after upgrading; progress, bookmarks, clippings, statistics, and other user state are stored separately and remain preserved.

## Firmware

For an X3 or standard X4, flash `CrossInk-AO3-v1.5.1-ao3.11-x3-x4.bin`. The boot screen should report `1.5.1-ao3.11`.

Do not flash the X3/X4 image on X4 Pro, X4 Classic, or Sticky hardware. Those devices require their board-specific build.

## Validation

- Production X3/X4 firmware build passed and the image fits its OTA partition with 398,416 bytes free.
- All 11 focused AO3 parser and rating-filter tests passed.
- 401 of 408 configured host tests ran and passed. Seven tests were not built because the installed macOS SDK marks floating-point `std::from_chars` unavailable; this is an upstream host-toolchain limitation and did not affect the embedded production build.

## Lineage

This fork uses [CrossInk](https://github.com/uxjulia/CrossInk) as its base and selectively adapts the AO3 concepts pioneered by [AvesO3](https://github.com/SiliconAves/AvesO3). AO3 EPUBs continue to open in the normal CrossInk reader.
