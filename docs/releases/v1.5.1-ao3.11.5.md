# CrossInk AO3.11.5

AO3.11.5 is a focused X3/X4 reliability release for the end-of-book and on-device AO3 update paths. It does not include the larger CrossInk 1.6 reader or Library upgrade.

## End-of-Book Reliability

- The reader now prevents automatic sleep while the end-of-book recommendation screen is active.
- Opening a suggested book, returning to the last page, and returning Home continue to use the faster AO3.11.4 transitions.
- The change applies to the standard CrossInk end-of-book recommendation screen as well as AO3 series suggestions because both share the normal EPUB reader endpoint.

## AO3 Update Memory Safety

- Before an AO3 update check or chapter download starts, the firmware checks total internal heap and the largest contiguous allocation.
- X3/X4 require at least 64 KiB free and a 50 KiB contiguous block before starting the HTTPS operation.
- If the requirement is not met, the original EPUB remains untouched and the device displays a recoverable low-memory message instead of attempting a fragile TLS allocation.
- The existing streamed AO3 parser, temporary download, EPUB/work-ID validation, backup, rollback, cache-preserving rebuild, and silent network restart remain unchanged.

## Firmware

For an X3 or standard X4, flash `CrossInk-AO3-v1.5.1-ao3.11.5-x3-x4.bin`. The boot screen should report `1.5.1-ao3.11.5`.

Do not flash the X3/X4 image on X4 Pro, X4 Classic, or Sticky hardware. Those devices require their board-specific build.

## Compatibility

No AO3 reindex, cache deletion, settings reset, or archive migration is required.

## Validation

- Production ESP32-C3 X3/X4 firmware build passed with 388,896 bytes free in the OTA partition.
- The non-touch application audit passed.
- The focused AO3 memory-policy tests passed 3/3.
- The full native test build is blocked on this macOS host because its C++ library marks floating-point `std::from_chars` unavailable; the failure occurs in the existing CSS parser test target and is unrelated to this release's changes.
- Hardware validation is required for end-of-book wake behavior and live AO3 TLS/download behavior.
