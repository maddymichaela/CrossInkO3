# CrossInk AO3.11.4

AO3.11.4 restores end-of-book series continuation prompts after the configurable Read folder was introduced in AO3.11.3.

## Series Recommendations

- Later works in the same indexed AO3 series are considered in series order.
- Works inside the selected Read folder remain excluded as intended.
- Excluded archived installments no longer consume the three available recommendation slots, so later unread installments can appear.
- If no eligible AO3 series work exists, the existing version 10 same-folder fallback remains unchanged.

## Firmware

For an X3 or standard X4, flash `CrossInk-AO3-v1.5.1-ao3.11.4-x3-x4.bin`. The boot screen should report `1.5.1-ao3.11.4`.

Do not flash the X3/X4 image on X4 Pro, X4 Classic, or Sticky hardware. Those devices require their board-specific build.

## Compatibility

No AO3 reindex, cache deletion, or settings reset is required.
