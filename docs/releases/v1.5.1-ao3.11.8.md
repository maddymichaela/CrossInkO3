# CrossInk AO3.11.8

AO3.11.8 fixes the remaining X3 update-check failure found after AO3.11.7 successfully refreshed 198 works in 50-work batches.

## AO3 Update Fetching

- AO3 update checks still request the full-work view so Explicit and chaptered works do not depend on redirect cookies.
- The streaming request now stops successfully as soon as both the update date and chapter count have been parsed.
- A representative chaptered work returned the required fields near byte 16,000 but approximately 185,000 bytes of full-work HTML overall. The X3 no longer receives the unnecessary remainder before showing the update result.
- Existing HTTP users keep the previous behavior: a callback returning false remains an error unless that request explicitly enables successful early completion.
- EPUB download, validation, backup, rollback, cache-preserving installation, and reading-position restoration are unchanged.

## Firmware

For an X3 or standard X4, flash `CrossInk-AO3-v1.5.1-ao3.11.8-x3-x4.bin`. The boot screen should report `1.5.1-ao3.11.8`.

Do not flash the X3/X4 image on X4 Pro, X4 Classic, or Sticky hardware.

## Compatibility

No AO3 reindex, cache deletion, settings reset, or archive migration is required.

## Validation

- AO3.11.7 hardware validation successfully refreshed 198 works in 50-work batches.
- Focused parser coverage verifies that streamed parsing signals completion immediately after both required fields arrive.
- Production ESP32-C3 X3/X4 firmware compilation validates the integrated target.
- Hardware validation is still required for the live update check and subsequent EPUB download.
