# CrossInk AO3.11.11

AO3.11.11 fixes the remaining X3 HTTP 403 failure after AO3.11.10's EPUB fallback was still denied before AO3 could redirect it to the separate file server.

## Direct File Host

- EPUB checks now contact `download.archiveofourown.org` directly.
- This bypasses `archiveofourown.org` and `archiveofourown.gay`, which returned HTTP 525 and 403 respectively during verification while the direct file host returned HTTP 200.
- The front domains remain secondary download routes in case AO3 changes its file-host behavior.

The reported public work returned a valid 302,758-byte EPUB from the direct host during verification.

## Download Safety

The EPUB is still streamed to SD, opened as a ZIP/EPUB, and checked for the exact AO3 work ID, update date, and completion state before replacement. Existing backup, rollback, cache rebuilding, and reader-data preservation remain in place.

## Firmware

For an X3 or standard X4, flash `CrossInk-AO3-v1.5.1-ao3.11.11-x3-x4.bin`. The boot screen should report `1.5.1-ao3.11.11`.

Do not flash the X3/X4 image on X4 Pro, X4 Classic, or Sticky hardware.

No AO3 reindex, cache deletion, settings reset, or archive migration is required.
