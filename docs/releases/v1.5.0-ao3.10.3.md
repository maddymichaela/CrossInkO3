# CrossInk AO3.10.3

AO3.10.3 is a notes-only historical Release entry covering the compatibility and validation period while this fork moved to the newer CrossInk base. Its tag references the final validated CrossInk 1.5.0 source line.

The completed compatibility work was rolled directly into `v1.5.1-ao3.11`, avoiding an extra firmware build that would immediately be obsolete. There is therefore no `ao3.10.3` binary to flash. Use `ao3.10.2` to remain on the CrossInk 1.5.0 base, or `ao3.11` for the completed CrossInk 1.5.1 integration.

No functional firmware changes are claimed for this marker, and no asset from another version should be renamed or attached to it.
