# CrossInk AO3.11.2

AO3.11.2 addresses slow reader exits, metadata refreshes, and end-of-book series handoffs while retaining the complete AO3.11 feature set and CrossInk 1.5.1 reader behavior.

## Performance Fixes

- Returning from a WIP or manually updated AO3 status no longer makes Home rescan every AO3 sidecar. Waiting and New Chapter totals update in the existing cached summary.
- Moving a finished AO3 fic to `/Read` keeps the same cached library totals instead of forcing a redundant Home scan.
- **Re-read indexed AO3 EPUBs** now considers only known AO3 works under the selected AO3 folder. It does not walk unrelated book folders or attempt to refresh ordinary EPUBs.
- Refresh collection stops as soon as the configured batch of up to 50 works is ready.
- AO3 sidecar locations are cached compactly after the first library scan, making same-series lookup and repeated library-page resolution much faster.
- Selecting a same-series work releases the old suggestion UI before the next EPUB loads, reducing memory pressure during the handoff.

A forced metadata refresh still needs to open and parse each AO3 EPUB selected for that batch. The improvement removes unrelated scans and repeated sidecar work around that necessary parsing.

## Compatibility

- No AO3 index migration is required.
- No EPUB cache rebuild is required.
- CrossInk progress, status bar, page counts, time-left estimates, bookmarks, clippings, and reading statistics are unchanged.

## Firmware

For an X3 or standard X4, flash `CrossInk-AO3-v1.5.1-ao3.11.2-x3-x4.bin`. The boot screen should report `1.5.1-ao3.11.2`.

Do not flash the X3/X4 image on X4 Pro, X4 Classic, or Sticky hardware. Those devices require their board-specific build.
